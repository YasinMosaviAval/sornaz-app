# میزان آزاد در نت‌نویس Flutter

در شاخهٔ توسعه، صفحهٔ شروع نت‌نویسی گزینهٔ «میزان آزاد (بدون میزان)» را در بالای منوی میزان‌نما با متن و نماد ∞ نمایش می‌دهد. پس از لمس کلاویه یا سکوت، زمان از ۰٫۰۱ تا ۵ ثانیه با گام ۰٫۰۱ وارد می‌شود؛ ارقام فارسی و انگلیسی و ممیز فارسی پذیرفته می‌شوند. زمان نت موجود از ابزار «زمان (ثانیه)» قابل ویرایش است و نت‌های بعدی همان صدا جابه‌جا می‌شوند.

این قابلیت در دارایی‌های بسته‌بندی‌شدهٔ خود Flutter پیاده شده است. تغییر فایل‌های وبسایت به‌تنهایی اپ نصب‌شده را به‌روزرسانی نمی‌کند. پس از ورود نسخهٔ تازه به چرخهٔ مجاز انتشار و نصب، کاربر گزینه را در اپ خواهد داشت؛ در این درخواست APK/AAB یا خروجی برنامه ساخته نشده است.

## رفتار و سازگاری

- متر آزاد میزان‌نما، خط/شمارهٔ میزان و سکوت‌های تکمیل‌کننده ندارد. زمان هر نت یا سکوت روی حامل و PDF نوشته می‌شود؛ سطرها متناسب با عرض صفحه می‌شکنند.
- پخش از تمپو مستقل است و حداقل قدیمی ۳۰ میلی‌ثانیه یا دنبالهٔ اضافی صداساز به نت ۰٫۰۱ ثانیه تحمیل نمی‌شود.
- در هر سه تنظیم انتخاب کشش، لمس پیانوی native پنجرهٔ زمان را باز می‌کند. انتخاب معلق هایلایت می‌شود، ورود کلاویهٔ دیگر تا بستن پنجره غیرفعال است و Back یا لمس پیانوی پشت پنجره بدون درج نت آن را می‌بندد.
- خانواده، اندازه و وزن قلم پنجره و برچسب زمان و شعاع گوشه از تنظیمات مشترک ظاهر می‌آیند. قلم انتخابی برای برچسب‌های PDF نیز معرفی می‌شود.
- ذخیره، بازگشایی، آپلود صریح و JSON از مسیرهای فعلی استفاده می‌کنند. `metadata.time` برابر `free` و `durationSeconds` هر نت عددی در بازهٔ مجاز است. موقعیت‌های صحیح مدل با وب و سرور یکسان‌اند؛ schema آپلود همچنان ۳ است.
- بلوک‌های داخلی حداکثر ۱۲۸ نت و ۶۴ بلوک فقط ظرف ذخیره‌سازی هستند؛ فاصلهٔ موسیقایی یا سکوت اضافی ایجاد نمی‌کنند. حامل‌ها و صداها مستقل‌اند.
- تغییر نوع مترِ بخش دارای نت، خروجی MusicXML متر آزاد و تصحیح خودکار تمرین نوشتاری برای این حالت پشتیبانی نمی‌شوند. برای متر متفاوت بخش خالی بسازید یا انتخاب کنید؛ ترکیب بخش آزاد و عددی در یک قطعه طبق `docs/notation-section-meters.fa.md` پشتیبانی می‌شود. در تمرین نوشتاری گزینهٔ آزاد نمایش داده نمی‌شود و ورود JSON آزاد رد می‌شود. برای متر آزاد JSON/PDF موجود است.
- نت‌های میزان‌بندی‌شده، پیانوی تیونر، تأییدهای حذف مشترک، کاتالوگ‌ها، مجوزها، جداکردن دادهٔ حساب‌ها، OMR و تحلیل آزمایشی از پیاده‌سازی فعلی استفاده می‌کنند. آداپتورهای اختصاصی وبسایت به اپ کپی نشده‌اند.

## فایل‌های قابل انتقال انتخابی

هشت فایل runtime باید با هم منتقل شوند؛ میزبان Dart و `pubspec.yaml` به تغییر نیاز نداشتند:

1. `assets/notation/model.js`
2. `assets/notation/importer.js`
3. `assets/notation/score_renderer.js`
4. `assets/notation/ui_glyphs.js`
5. `assets/notation/ui_controls.js`
6. `assets/notation/ui_controls.css`
7. `assets/notation/notation.css`
8. `assets/notation/notation.js`

آزمون‌ها و این راهنما نیز برای نگهداری تغییر منتقل شوند:

- `test/notation_free_meter_api_test.dart`
- `tools/notation_free_meter_model_check.cjs`
- `tools/notation_free_meter_check.cjs`
- `docs/notation-free-meter.fa.md`

وابستگی تازه، migration، تغییر شناسهٔ برنامه، امضا، تنظیمات backend یا وابستگی جدید به OMR/تحلیل آزمایشی وجود ندارد. پیش‌نیازهای نت‌نویس فعلی شامل Bravura، پیانوی مشترک و کنترل‌های نمادین باید در مقصد حاضر باشند. `AGENTS.md` و ویژگی‌های خارج از انتشار منتقل نشوند. worktree انتشار در این کار تغییر نکرده است.

پیش از انتشار اپ، سرور مقصد باید اعتبارسنج متر آزاد را در `Modules/Notation/Services/NotationService.php` و شرط رد آن در تصحیح نوشتاری داشته باشد؛ سورس این پشتیبانی قبلاً در مخزن وب تهیه شده، اما استقرار واقعی سرور در این کار تأیید نشده است. سرور قدیمی ممکن است آپلود متر آزاد را رد کند؛ ذخیرهٔ محلی باقی می‌ماند. فایل سرور، migration اصلی یا تنظیم واقعی سرویس در این درخواست تغییر نکرده است.

برای بازگشت پیش از ایجاد قطعهٔ آزاد، مجموعهٔ هشت‌فایلی قبلی را بازگردانید. پس از ایجاد دادهٔ آزاد، بازگشت به خوانندهٔ قدیمی باعث پشتیبانی‌نشدن آن قطعه می‌شود؛ داده‌های حساب یا JSON را حذف نکنید. برای توقف عرضهٔ ایجاد قطعهٔ جدید، `freeMeterEnabled: false` در پیکربندی ویرایشگر قابل استفاده است؛ خواندن و ویرایش دادهٔ آزاد با موتور جدید حفظ می‌شود.

## آزمون‌ها

```sh
node tools/notation_free_meter_model_check.cjs
node tools/notation_free_meter_check.cjs
flutter test --no-pub test/notation_free_meter_api_test.dart test/notation_instruments_api_test.dart test/notation_scales_api_test.dart test/shared_piano_keyboard_test.dart test/notation_top_bar_test.dart test/notation_delete_confirmation_test.dart test/music_practice_notation_test.dart
node tools/notation_repeat_recovery_check.cjs
node tools/notation_copy_repeats_check.cjs
```

نتیجهٔ محلی: ۲۸ آزمون Flutter، آزمون مدل متر آزاد و ۱۲ سناریوی مرورگر با دارایی‌های واقعی اپ و پل پیانوی native موفق‌اند. سناریوها فارسی/انگلیسی، عرض ۳۹۰/۱۲۸۰، روشن/تاریک و سه حالت انتخاب کشش را پوشش می‌دهند و انتخاب منوی دیداری، مرز زمان، ورودی فارسی، لغو، هایلایت معلق، غیرفعال‌شدن پیانو، مقیاس/وزن قلم، شعاع، ویرایش، ذخیره، واگرد/ازنو، زمان‌بندی صداساز و چاپ را می‌سنجند. ارتباط ذخیره/آپلود مرورگر ساختگی است؛ آزمون Dart خود `NotationApi` و SharedPreferences را با HTTP ساختگی برای حفظ داده و جداسازی حساب‌ها اجرا می‌کند.

بازیابی نت‌های قدیمی در چهار سناریوی زبان/عرض، پخش، واگرد/ازنو، ذخیره و خواندنی، و نیز کپی خواص نت/میزان، برخورد اتمی و ساختار تکرار موفق‌اند. تحلیل Dart آزمون جدید بدون مورد، نحو JavaScript و `git diff --check` موفق‌اند.

آزمون قدیمی `tools/notation_duration_dialog_check.cjs` در fixture خط ۱۵ به کنترل حذف‌شدهٔ palette ارجاع می‌دهد و شکست می‌خورد؛ همان خطا با فایل‌های `HEAD` پیش از این تغییر نیز بازتولید شد. این fixture قدیمی در این درخواست تغییر نکرده است. نتیجهٔ موفق دوازده سناریوی جدید جای این خطای قدیمی را پنهان نمی‌کند.

آزمون فیزیکی Android/iOS، چاپ سیستم‌عامل، سرور واقعی و نسخهٔ نصب‌شده انجام نشده‌اند. برای بررسی پس از انتقال مجاز، روی دستگاه یک قطعهٔ آزاد با ۰٫۰۱ و ۵ ثانیه و سکوت ۰٫۲۹ بسازید، برنامه را ببندید و باز کنید، داده را بازخوانی و JSON/PDF بگیرید؛ سپس با سرور تست سازگار آپلود صریح، رد دسترسی کاربر دیگر و تعارض نسخه را بررسی کنید. یک قطعهٔ ۴/۴ قدیمی نیز باید بدون تغییر باز و پخش شود.
