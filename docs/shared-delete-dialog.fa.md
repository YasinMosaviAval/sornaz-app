# دیالوگ مشترک حذف

مرجع رابط، حذف ابزار ویدیو است. `lib/components/app_dialog.dart` شامل بدنهٔ مشترک `AppDialog`، دکمهٔ `AppDialogAction` و تأیید حذف `DeleteConfirmationDialog` است. عنوان ۱۴dp، متن و دکمه‌ها ۱۲dp، حذف قرمز و انصراف خاکستری‌اند. خانواده و وزن قلم، سطح روشن/تاریک و گردی گوشه‌ها از تم برنامه می‌آیند.

برای حذف دوگزینه‌ای، `await showDeleteConfirmation(context, title: ..., message: ...)` فراخوانی شود. فقط `true` مجوز ادامهٔ حذف است؛ انصراف، لمس بیرون و Back مقدار `false` می‌دهند. متن باید قبل از فراخوانی با قرارداد ترجمهٔ همان صفحه آماده شود. helper به داده، API یا فایل دسترسی ندارد؛ عملیات حذف بعد از تأیید در محل قبلی باقی می‌ماند.

در انتخاب‌های چندگانه مانند «حذف از فهرست / حذف از حافظه» و «ذخیره / حذف / ادامهٔ ضبط»، از `AppDialog` و نقش‌های `cancel`، `destructive` و `primary` استفاده می‌شود. همهٔ مسیرهای قبلی حذف و پیام‌های خطا حفظ می‌شوند. `PlayerDialog` نیز بدنهٔ مشترک را استفاده می‌کند.

ورودی‌های حذف ویدیو، موسیقی، فهرست‌های پخش، ضبط و نشانه‌های صوتی، آزمون‌ها، شعبه و نوع آموزشی، حذف‌های پنل، فایل جلسات، گالری، هایلایت، پست، بخش دوره و دانلودها به این ساختار متصل‌اند. wrapperهای قبلی مانند `confirmMediaDelete`، `confirmRecordingDelete` و `showPanelConfirmation` برای سازگاری باقی مانده‌اند.

در آزمون‌ها آیکن فلش کارت حذف، سطل زباله قرمز و عنوان کارت‌ها ۱۴dp است. کارت اجرای آزمونِ سطح جاری فقط وقتی دادهٔ آزمون مستقیماً به همان `nodeId` متصل باشد نمایش داده می‌شود؛ وجود آزمون در فرزندان برای نمایش آن کافی نیست.

فایل تازهٔ ویجت باید همراه تمام مصرف‌کنندگان تغییرکرده منتقل شود. وابستگی یا migration جدید، تغییر سرور و ساخت APK لازم نیست. تغییرات فقط در شاخهٔ توسعه‌اند و برای انتقال انتخابی به انتشار، ویجت و مصرف‌کنندگان باید با هم منتقل شوند. وابستگی تازه‌ای به OMR یا قابلیت‌های آزمایشی اضافه نشده است.
