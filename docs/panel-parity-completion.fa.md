# تکمیل امکانات پنل وب در اپ

مبنای تطبیق، catalog بخش‌ها و عملیات پنل وب و رابط بومی موجود بود. کتابخانهٔ مستندات مدیر، نمایش بومی گالری ۱۹ نمودار، همگام‌سازی جدول‌های مالی/نوشته‌ها و دکمهٔ مشاهدهٔ دسترسی‌ها تکمیل شدند. راهنماهای ترجمه‌شده همچنان از قرارداد قبلی استفاده می‌کنند. حساب، تنظیمات و آزمون‌ها مسیرهای بومی فعلی را دارند.

## فایل‌های انتقال انتخابی

فایل‌های جدید: `lib/screens/Site/panel_guides.dart`، `panel_chart_gallery.dart`، `lib/components/charts/app_sample_chart.dart`، `lib/helpers/chart_export.dart`، `assets/panel/chart-gallery.json` و `tools/sync_panel_chart_gallery.cjs`.

فایل‌های موجود مرتبط: `lib/screens/Site/panel_api.dart`، `panel_resource_page.dart`، `site_panel_page.dart`، `panel_insight_charts.dart`، `panel_web_contracts.dart` و ثبت asset در `pubspec.yaml`. وابستگی جدید اضافه نشده است. این تغییر به OMR یا تحلیل اجرای آزمایشی وابسته نیست. تغییرهای دیگر همین worktree، به‌خصوص آزمون‌های موسیقی، جداگانه منتقل شوند. فایل AGENTS شاخهٔ release بازنویسی نشود.

## قراردادها و بررسی

API نسخهٔ قابلیت ۵، metadata کتابخانه را فقط برای مدیر اصلی می‌فرستد. متن مستندات فقط هنگام بازکردن بارگیری می‌شود، cache خصوصی ندارد، تغییر حساب ویرایشگر را غیرفعال می‌کند و ذخیره/حذف نسخهٔ قدیمی رد می‌شود. سرور قدیمی بدون کتابخانه نیز پشتیبانی می‌شود. جزئیات انتشار وب در `docs/mobile-panel-parity-completion.fa.md` مخزن وب ثبت شده‌اند؛ وب باید پیش از اپ منتشر شود.

گالری از دادهٔ نمونهٔ خود وب ساخته می‌شود:

```text
node tools/sync_panel_chart_gallery.cjs A:/workspace/web/sornaz
```

خروجی شامل SHA256 منبع با newline یکسان است. نمودار خطی ساده از `AppLineChart` موجود استفاده می‌کند و انواع دیگر با `AppSampleChart` رسم می‌شوند. PNG گالری و نمودارهای گزارش از helper مشترک استفاده می‌کند. این گالری نمونهٔ ثابت است و دادهٔ حساب را دریافت نمی‌کند؛ شرط دسترسی منوی سرور حفظ شده است.

`test/panel_library_gallery_test.dart` بسته‌بندی asset، ۱۹ نوع در دو حالت و دو تم، لمس داده، فیلتر و PNG واقعی، lazy load راهنما، حفظ متن هنگام conflict، انصراف حذف، تغییر حساب و جلوگیری از cache را می‌سنجد. آزمون‌های قدیمی گالری، فرم گفتگو، تنظیمات شخصی و نام تب حساب با قرارداد فعلی هماهنگ شدند؛ ارسال تنظیمات مختص مدیر برای کاربر عادی مجاز نشده است. آزمون‌های نقش/مسیر API نیز در مخزن وب وجود دارند. دستگاه فیزیکی، انتشار و ساخت APK در این کار انجام نشده‌اند.

اجرای مجموعهٔ پنل و کارت‌های حساب: ۲۰۵ آزمون موفق. پس از اصلاح صرفاً سبک کد، ۲۱ آزمون کتابخانه/گالری/خروجی نمودار دوباره موفق شدند. تحلیل فایل‌های جدید بدون مسئله بود؛ در فایل‌های قدیمی بررسی‌شده فقط تذکرهای سبک آکولاد باقی بود. `git diff --check` و بررسی syntax ابزار همگام‌سازی موفق بودند.
