# انتخاب کشش پس از لمس نت یا سکوت — ۷ نوامبر ۲۰۲۶

لمس کوتاه کلاویه یا سکوت، منبع انتخاب را با رنگ اصلی تم هایلایت و شبکهٔ کشش‌ها را باز می‌کند. انتخاب یکی از گزینه‌ها همان ارتفاع/علامت و کشش را با مسیر فعلی ورود نت ثبت می‌کند. دیالوگ عنوان دیداری و دکمهٔ انصراف ندارد؛ نام دسترس‌پذیر آن حفظ شده است. لمس بیرون، Escape و Back بدون تغییر نت‌ها انتخاب را لغو و هایلایت را پاک می‌کنند. بازشدن دیالوگ ورودی دوبارهٔ پیانو را غیرفعال می‌کند. انتخاب مدت نت و سکوت یک پیاده‌سازی `chooseDuration` دارد؛ محدودیت سکوت سفید نقطه‌دار حفظ شده است.

`nativePianoState.selectedKeyId` انتخاب معلق را از موتور وب به `NotationPianoKeyboard` می‌فرستد؛ ویژگی اختیاری `AppPianoKeyboard.selectedKeyId` هایلایت را مستقل از نگه‌داشتن انگشت حفظ می‌کند. `durationPickerOpen` باعث می‌شود لمس پیانوی native زیر دیالوگ فقط رویداد `dismiss` بفرستد و بدون ورود نت دیالوگ را ببندد. تیونر بدون انتخاب معلق رفتار قبلی را دارد. راهنمای لمس طولانی، لغو هنگام اسکرول و کشیدن عمودی برای انتخاب کشش حفظ شده‌اند؛ لمس کوتاه در هر دو تنظیم قدیمی کشش از دیالوگ استفاده می‌کند.

بخش «میزان و تکرار» و دکمهٔ بازکردن ابزار میزان از دیالوگ ابزار نت حذف شده‌اند؛ ابزار میزان از دکمهٔ مستقل بالای صفحه قابل استفاده است. برچسب فیلدهای نت و ریتم، علائم تغییر ارتفاع، دینامیک و زینت پیش از منوی انتخاب رندر می‌شوند و بالای آن قرار می‌گیرند.

## فایل‌ها و انتقال انتخابی

- `lib/components/app_piano_keyboard.dart` و `lib/screens/Notation/notation_piano_keyboard.dart` برای انتخاب معلق native.
- `assets/notation/notation.js` و `assets/notation/notation.css` برای دیالوگ و دسته‌بندی ابزارها؛ پیش‌نیازهای مرحلهٔ قبل شامل Bravura، `ui_controls.css` و پل پیانوی مشترک باید حاضر باشند.
- آزمون‌های اصلاح‌شدهٔ نت‌نویسی، `test/notation_duration_dialog_test.html` و `tools/notation_duration_dialog_check.cjs` برای نگهداری و بررسی رفتار جدید.

API، دادهٔ نت، migration و وابستگی جدید نداریم. APK، خروجی برنامه و بستهٔ انتشار ساخته نشده و worktree انتشار تغییر نکرده است. تغییرهای وب نیز در مخزن وب اعمال شده‌اند.

## اعتبارسنجی

آزمون Flutter انتخاب معلق را با ورودی غیرفعال، رنگ اصلی تم و پاک‌شدن هایلایت می‌سنجد؛ آداپتور تیونر و ورود دیز/بمل نیز بررسی می‌شوند. fixture جدید ثبت کشش نقطه‌دار، لغو بدون ثبت، وضعیت پل native و جای عنوان‌های ابزار را بررسی می‌کند. آزمون واقعی Playwright در فارسی/انگلیسی، تم روشن/تاریک و عرض‌های ۳۹۰/۱۲۸۰، لمس بیرون، ثبت نت/سکوت، انتخاب بمل native و رنگ/شعاع انتخابی را بررسی و تصویر ذخیره می‌کند. آزمون روی دستگاه فیزیکی انجام نشده است.

نتیجه: ۴ آزمون Flutter و ۱۶ سناریوی تعامل واقعی اپ/وب موفق‌اند؛ ۸ بررسی تصویری قبلی واحد ضرب، سکوت و پیانو نیز پس از تغییر موفق ماندند. تحلیل Dart فایل‌های تغییرکرده بدون مورد، نحو JavaScript و `git diff --check` موفق‌اند. آزمون‌های گروهی ابزارهای وب، فرم، ذخیره/بارگذاری و fixtureهای مشترک نیز موفق‌اند. این مرحله آزمون کامل انتشار را تکرار نمی‌کند؛ نتیجهٔ قبلی آن در راهنمای مرحلهٔ قبل جدا ثبت شده است.
