# خروجی iOS

شناسهٔ برنامه، تنظیمات امضا، بک‌اند و worktree انتشار تغییر نکرده‌اند.
SDK قفل‌شدهٔ ساخت Flutter 3.47.2 و حداقل نسخهٔ iOS پروژه 15 است.

## ساخت و دریافت

Workflow با نام `iOS unsigned build` روی مک استاندارد GitHub Actions اجرا می‌شود.
اجرای دستی از تب Actions ممکن است. برای ساخت هنگام پوش، عبارت `[build-ios]`
باید در پیام کامیتِ شامل تغییر iOS باشد؛ پوش عادی خروجی برنامه تولید نمی‌کند.
نسخهٔ Release دستگاه جدا از نسخهٔ Debug تشخیصی شبیه‌ساز ساخته می‌شود.
Artifact شامل IPA بدون امضا، SHA-256، نتیجهٔ بررسی بومی و راهنمای کوتاه است.
نگهداری artifact یک روز است؛ آن را پس از ساخت دانلود و نگهداری کنید.
گزارش JSON و لاگ شبیه‌ساز در artifact جداگانهٔ `Sornaz-iOS-diagnostics`،
حتی هنگام شکست بررسی بومی، نگهداری می‌شوند. بستهٔ IPA تنها پس از موفقیت بررسی‌ها ساخته می‌شود.

IPA بدون امضا روی آیفون نصب نمی‌شود. نصب، TestFlight یا انتشار به گواهی،
provisioning و حساب Apple مناسب نیاز دارد. هیچ اطلاعات امضایی در workflow ذخیره
یا ساخته نشده و هیچ خروجی به App Store Connect فرستاده نمی‌شود.

برای ساخت محلی روی مک، پس از آماده‌کردن Xcode، CocoaPods و Rust:

```sh
flutter pub get --enforce-lockfile
dart run tool/prepare_ios.dart
rustup target add aarch64-apple-ios
flutter build ios --release --no-codesign --no-pub
```

اسکریپت آماده‌سازی، هشت XCFramework وابستگی FFmpeg را از اسکریپت همان بستهٔ
قفل‌شده آماده می‌کند؛ برای کش ناقص خطای صریح می‌دهد. ساخت اولیه به شبکه نیاز دارد.

## قابلیت‌ها و تفاوت‌ها

| بخش | پیاده‌سازی iOS |
| --- | --- |
| موسیقی | کنترل رسانهٔ سیستم، پخش پس‌زمینه، اکولایزر و واردکردن کپی فایل صوتی از Files |
| ضبط | برش و جایگزینی امن، ادامهٔ ضبط، موج صوتی و پوشهٔ دارای مجوز پایدار |
| تیونر | دریافت PCM و تشخیص فرکانس به‌جای افزونهٔ نمونهٔ فاقد تشخیص iOS |
| مترونوم | حلقهٔ AVAudioEngine روی ساعت صوتی، شدت صدای مستقل، توقف با زمان یا تعداد میزان |
| ویدیو | فهرست Photos، انتخاب دسترسی محدود، پیش‌نمایش، پخش فایل انتخابی، برش و تبدیل |
| واردکردن ویدیو | ساخت کپی H.264/AAC سازگار با Photos از فایل انتخاب‌شده؛ اصل فایل حفظ می‌شود |
| استوری | گالری، دوربین، لایه‌ها، خروجی H.264 با AVFoundation و ذخیره در Photos |
| PDF خصوصی | رندر داخلی PDFKit؛ فایل رمزگشایی‌شده به برنامهٔ بیرونی فرستاده نمی‌شود |
| نت‌نویسی | ویرایشگر WebView، خروجی Files/اشتراک‌گذاری/چاپ و انتخاب پوشه |
| OMR و تحلیل | همان مجوز توسعه، دریافت تصویر دوربین و موتور بومی باز موجود |

iOS اجازهٔ اسکن کل حافظهٔ مشترک اندروید یا تنظیم مستقیم زنگ سیستم را نمی‌دهد.
فایل‌ها از Files انتخاب می‌شوند و رسانه‌ها با مجوز Photos خوانده یا ذخیره می‌شوند.
برای ویدیوی واردشده، برش و استوری، FFmpeg ابتدا پیش‌نویس MPEG-4 می‌سازد و
AVFoundation خروجی نهایی MP4 را تولید می‌کند؛ حذف پیش‌نویس پس از موفقیت تبدیل
انجام می‌شود. بستهٔ FFmpeg قفل‌شدهٔ iOS رمزگذار `h264_videotoolbox` ندارد.
نام منابع اصلی Photos قابل تغییر نیست؛ تغییر نام در برنامه، عنوان نمایشی را
نگهداری می‌کند و اصل منبع را حذف یا جایگزین نمی‌کند. اشتراک‌گذاری برنامه در iOS
پیوند سایت را می‌فرستد و درخواست ساخت یا اشتراک APK ندارد.

## بررسی‌ها

آزمون‌های مشترک، مسیر iOS، گالری محدود، انتخاب پوشه و حفظ فایل‌ها را می‌سنجند.
ساخت Xcode و آزمون شبیه‌ساز بخشی از workflow هستند؛ موفقیت کامپایل به‌تنهایی
معادل تأیید همهٔ قابلیت‌ها نیست.

حالت `SORNAZ_IOS_SMOKE` تنها در ساخت تشخیصی شبیه‌ساز فعال می‌شود. این حالت
۲۱ بررسی بومی روی رسانهٔ مصنوعی اجرا می‌کند: پخش، قالب‌های خروجی، برش، اکولایزر،
استوری، PDF، Rust، تحلیل، مترونوم و رفت‌وبرگشت یک ویدیوی مصنوعی در Photos.
مجوز Photos فقط در شبیه‌ساز موقت CI اعطا می‌شود؛ دوربین و میکروفون ضبط نمی‌شوند
و هیچ حساب واقعی باز نمی‌شود. فایل IPA دستگاه این حالت را فعال نمی‌کند.

دوربین و میکروفون واقعی، تماس‌ها، لوازم صوتی، پوشه‌های iCloud، اعلان‌های سیستم،
امضا و گردش کامل حساب کاربری باید روی آیفون واقعی بررسی شوند.

## انتقال انتخابی

فایل‌های iOS، قراردادهای مشترک `desktop_media_channel.dart`، واردکردن فایل‌ها،
کنترلرهای پخش/ضبط/تیونر/مترونوم و آزمون‌های مرتبط باید هماهنگ منتقل شوند.
بخش‌های OMR و تحلیل به قابلیت‌های آزمایشی محیط توسعه وابسته‌اند؛ انتقال آن‌ها
به release باید جداگانه بررسی شود. فایل `AGENTS.md` انتشار نباید جایگزین شود.
