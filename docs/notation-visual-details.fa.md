# اصلاح جزئیات نمایش نت‌نویسی — ۷ نوامبر ۲۰۲۶

پیانوی مشترک تیونر و نت‌نویسی برچسب‌های هم‌اندازه و رنگ ربع‌پردهٔ مات دارد؛ مرز سفیدها از زیر آن دیده نمی‌شود. هر سیاه دو ناحیهٔ برابر دارد: بالایی دیز و پایینی بمل هم‌صدا، با املای مستقل هنگام ورود نت. پیانوی ویرایشگر به پایین صفحه می‌چسبد. فاصلهٔ عنوان و ردیف ابزارها ۴ پیکسل و عنوان‌ها «ابزار میزان» و «ابزار نت» هستند.

برای واحد ضرب، علت بریده‌شدن واقعی نماد، به‌ارث‌رسیدن جهت راست‌به‌چپ توسط متن SVG بود. جهت نماد Bravura صریحاً چپ‌به‌راست شده و پیش‌نمایش انتخاب‌شده و گزینه‌ها وسط‌چین‌اند. اندازهٔ نماد نصف حالت قبلی باقی مانده است. سکوت گرد/سفید خط مرجع بالا/پایین دارند؛ سکوت سفید نقطه‌دار و دونقطه‌دار فقط از انتخاب‌های تازه حذف شده‌اند و دادهٔ ذخیره‌شده حفظ می‌شود.

فضای خالی عمودی خطوط حامل در نمایشگر نصف می‌شود. ارتفاع CSS خود SVG نیز اصلاح شده تا فضای خالی ناشی از مقیاس حفظ نشود. محدودهٔ واقعی نت‌ها و تزئینات برای جلوگیری از برخورد اندازه‌گیری می‌شود؛ فاصلهٔ دو حامل نیز از ۱۵۰ به ۹۵ واحد کاهش می‌یابد و در حالت شلوغ افزایش می‌یابد. چیدمان چاپ فاصلهٔ قبلی خود را حفظ می‌کند.

## آزمون

۸ آزمون Flutter، ۲۶ آزمون مرورگر برای اپ و ۲۶ آزمون با فایل‌های واقعی وب موفق‌اند. ابزار `tools/notation_visual_details_check.cjs` در فارسی/انگلیسی و عرض‌های ۳۹۰/۱۲۸۰، پیکسل‌های واقعی نمادهای منو و مقدار انتخاب‌شده، وسط‌چینی، خط سکوت‌ها، پوشیده‌شدن مرز سفیدها، ورود دیز/بمل و فاصله‌های ۴ پیکسل را بررسی می‌کند؛ هشت اجرای اپ/وب موفق‌اند. آزمون فاصلهٔ حامل‌ها کاهش فضای خالی، رشد در حالت شلوغ و حفظ چاپ را می‌سنجد. تحلیل Dart اجزای مشترک و آزمون آن‌ها بدون مورد است؛ میزبان قدیمی فقط پیام‌های info دارد. خروجی تولیدی، نحو JavaScript و `git diff --check` موفق‌اند. بررسی عمومی وب ۱۴۱/۱۴۳ موفق است؛ دو شکست مربوط به فایل آزمون music-practice مفقود و آزمون وابسته است. یک شکست زمانی export access در اجرای مستقل موفق شد. آزمون دستگاه فیزیکی انجام نشده است.

## انتقال

تغییرهای Flutter در `lib/components/{app_piano_keyboard.dart,piano_keyboard_spec.dart}` و میزبان `lib/screens/Notation/music_sheets_page.dart` قرار دارند. خروجی تولیدی `piano_style.js` باید با ابزار همگام‌سازی ساخته شود. فایل‌های runtime وب/اپ: `assets/notation/{piano_style.js,ui_symbols.js,ui_controls.css,score_renderer.js,notation.js}`، همراه پیش‌نیازهای مرحلهٔ قبل. API، migration یا وابستگی تازه نداریم. APK ساخته نشده و worktree انتشار و سرور اصلی تغییر نکرده‌اند. راهنمای وب هم‌نام، ترتیب انتقال و بازگشت را مشخص می‌کند.
