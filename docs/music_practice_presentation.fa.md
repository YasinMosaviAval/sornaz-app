# نمایش درختی و مدیریت آزمون‌ها

نمای پیش‌فرض تب آزمون‌ها، برای همه از جمله مدیر سایت، فهرست بازشوندهٔ یک‌صفحه‌ای مانند پوشه‌های پخش موسیقی است. ردیف‌های سطح اول بدون زمینهٔ کارت‌اند؛ زیرسطح‌ها با تورفتگی در جهت زبان و رنگ زمینهٔ اندکی متفاوت از والد مشخص می‌شوند. رنگ از تم و رنگ اصلی انتخابی برنامه می‌آید. بازشدن هر ردیف آیکن آن را پُر و با رنگ اصلی نشان می‌دهد. باز و بسته‌کردن شاخه‌ها بین تازه‌سازی‌ها حفظ و هنگام تغییر حساب پاک می‌شود.

سطح‌های داخلی آزمون زیر بخش خود نشان داده می‌شوند. دکمهٔ «شروع / ادامهٔ آزمون» روی بخش، مسیر پیوسته و ادامه از نخستین مرحلهٔ کامل‌نشده را نگه می‌دارد؛ انتخاب یک سطح مشخص همان سطح را باز می‌کند. نتایج، ترتیب سرور، تعداد مراحل، خرید و کنترل مجوز آفلاین تغییر نکرده‌اند.

فقط مدیر سایت با شناسهٔ ۱ می‌تواند در تنظیمات، «نمایش آبشاری آزمون‌ها در یک صفحه» را خاموش و نمایش صفحه‌به‌صفحهٔ قبلی را انتخاب کند. پیش‌فرض این کلید تازه روشن است و انتخاب آن ذخیره می‌شود. تنظیم قبلی فهرست سطح‌های آزمون حذف نشده و در نمایش صفحه‌به‌صفحه همان رفتار قبلی را دارد. نمایش صفحه‌به‌صفحه نیز کارت زمینه ندارد.

عملیات ویرایش، انتشار، افزودن زیرسطح/آزمون، پیشنهاد اشتراک و حذف در منوی سه‌نقطهٔ همان ردیف قرار دارند. گزینه‌های غیرمجاز نمایش داده نمی‌شوند و محدودیت والد غیرفعال و تأیید حذف مشترک حفظ شده‌اند. پیشنهادهای اشتراک هم از منوی سه‌نقطه استفاده می‌کنند. انتقال عملیات به منو، مجوز API را تغییر نمی‌دهد.

پیام «نسخهٔ ذخیره‌شده؛ حالت آفلاین» و متن خطای شبکه در حالت آفلاین حذف شده‌اند؛ محتوای ذخیره‌شده باقی می‌ماند. خطای اتصال بدون کش نیز متن خطا نشان نمی‌دهد. رد دسترسی ۴۰۱/۴۰۳ همچنان کش خصوصی صفحه را کنار می‌گذارد و خطای دسترسی را نشان می‌دهد. خطاهای واقعی سرور در دریافت اجباری آنلاین پنهان نمی‌شوند. اعتبار مجوز امضاشده برای اجرای آفلاین تغییر نکرده است.

سازنده یا مدیر مجاز در فرم افزودن/ویرایش هر سه عمق بخش، یکی از ۱۴ آیکن آمادهٔ موسیقی یا حالت پیش‌فرض را انتخاب می‌کند. کلید پایدار `iconKey` در API ذخیره و همراه فهرست برای سایر کاربران و کش آفلاین دریافت می‌شود. آیکن ناشناخته یا فهرست قدیمی از نمایش پیش‌فرض استفاده می‌کند. انتخاب آیکن پس از دریافت قابلیت `nodeIcons: true` از سرور فعال می‌شود؛ ارسال فرم از اپ قدیمی آیکن موجود را پاک نمی‌کند. انتخاب تصویر از دستگاه در این درخواست مطرح نیست.

عنوان فرم بر اساس نوع و افزودن/ویرایش تعیین می‌شود: سطح، آزمون، پیشنهاد اشتراک، بررسی پیشنهاد و سهم درآمد. تمام عنوان‌ها و گزینه‌ها فارسی/انگلیسی‌اند و قلم و شکل کنترل‌ها از تم مشترک می‌آیند.

## وب و انتشار

برای ذخیرهٔ آیکن، تغییر سه سرویس وب و migration افزودنی لازم است. فهرست دقیق، ترتیب امن، بازگشت و آزمون پس از انتشار در پروژهٔ وب، `docs/music-practice-node-icons.fa.md` آمده است. نمایش درختی به‌تنهایی روی API قبلی کار می‌کند؛ انتخاب آیکن تا ارتقای API و schema غیرفعال می‌ماند. migration اصلی و انتشار انجام نشده‌اند.

آزمون‌های خودکار، گسترش هر سه عمق در یک صفحه، پیش‌فرض مدیر و کاربر، تنظیم اختصاصی مدیر، تم روشن/تاریک و انگلیسی روی عرض ۳۲۰، انتخاب و ارسال آیکن، عنوان فرم‌ها، منو و حالت آفلاین را بررسی می‌کنند. این آزمون‌ها جای آزمون لمسی روی گوشی واقعی و حساب سرور تست را نمی‌گیرند.

نتیجه: هر ۶۱ تست مجموعهٔ مرتبط (`music_practice_presentation`، `music_practice`، `music_practice_validation`، `music_practice_tree`، `music_practice_journey` و `main_tabs_notation`) موفق شدند. آزمون حفظ آیکن در کش پس از افزودن آن نیز جداگانه موفق بود. تحلیل فایل‌های تغییرکرده بدون اشکال و `git diff --check` موفق است. تست لمسی روی گوشی و انتشار انجام نشده‌اند.
