# اصلاح رابط حساب و ابزارهای نسخه انتشار

ورودی نت‌نویسی و سولفژ، پیشرفت یادگیری، دوره‌های کامل‌شده، دستاوردها، ساخت و مدیریت دوره، ذخیره‌شده‌ها، دانلودها و تنظیمات اعلان در رابط حساب انتشار برای همه حساب‌ها حذف شده‌اند. داده‌ها و وابستگی‌های مشترک حذف نشده‌اند.

فقط یک «درخواست ادغام حساب» در منو باقی است. فرم اتصال سابقه در همان صفحه، بدون باکس، با شناسه‌های معتبر و API موجود قابل ارسال است. دستگاه‌ها، اسناد، تاریخچه ورود و هشدارهای امنیتی از پیاده‌سازی ساده موجود استفاده می‌کنند و باکس جدیدی ندارند. فرم رمز و حریم خصوصی دکمه پایین با رنگ و شعاع مشترک تم دارند و آیکن ذخیره نوار بالا برای این دو فرم نمایش داده نمی‌شود.

فایل‌های این کار:
- lib/screens/Home/ui/pages/music_tools.dart
- lib/screens/Home/ui/components/app_drawer.dart
- lib/screens/Social/social_learning.dart
- lib/screens/Site/panel_form.dart
- lib/screens/Site/panel_resource_page.dart
- lib/screens/Site/account_membership_request.dart (جدید)
- test/account_production_ui_test.dart و test/account_plain_sections_test.dart (جدید)

هر ۱۱ آزمون جدید با flutter test --no-pub --dart-define=RELEASE_UI=true در دو فایل آزمون فوق موفق بودند. تحلیل فایل‌های مرتبط بدون error/warning است و infoهای سبک باقی‌اند. تغییرات انتخابی‌اند و امکانات OMR یا تحلیل آزمایشی توسعه وارد این شاخه نشده‌اند.

تغییرات محلی قبلی AGENTS.md، .gitignore و scripts دست‌نخورده و خارج از کامیت این کارند. API جدید، migration، تغییر شناسه برنامه/امضا/backend یا خروجی برنامه ساخته نشده است. وب به تغییر نیاز نداشت.

این اصلاح تأیید انتشار نهایی نیست: مشکل قدیمی صفحه سیاه شروع Release هنوز نیازمند بررسی روی Android واقعی است. قبل از انتشار، شروع برنامه و تغییر حساب/فرم‌ها روی دستگاه بررسی شوند. برای rollback همین کامیت انتشار برگردانده شود و AGENTS.md شاخه حفظ شود.
