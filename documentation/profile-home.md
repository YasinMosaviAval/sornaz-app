# خانه و صفحات پروفایل

خانه بر اساس Figma node 1111:10176 بازطراحی شده: جست‌وجو، فیلتر قیمت، مقاله‌ها، دوره جدید، دوره‌های به‌روزشده، مسیر شروع یادگیری و مدرسان. کارت‌ها از API واقعی پر می‌شوند و حالت خالی/خطا/تلاش دوباره دارند. هر دو تم و زبان فارسی/انگلیسی پشتیبانی می‌شوند.

برای بخش پروفایل node 1099:5395 ساختار صفحات دریافت شد، اما سهمیه Figma پیش از دریافت جزئیات زیرصفحه‌ها تمام شد. نمای حساب، ویرایش، ذخیره دوره و نویسنده، دانلود، تنظیمات اعلان، پیشرفت و دستاوردها بر اساس ساختار دریافت‌شده و اجزای موجود پیاده شده‌اند؛ تطابق کامل جزئیات بصری این زیرصفحه‌ها تأیید نشده است.

ناوبری پنج‌قسمتی خانه، ابزار موسیقی، دوره‌ها، مقاله‌ها و پروفایل است. چون پروژه صفحه نت موسیقی ندارد، ابزارهای قبلی پخش، تیونر، مترونوم و ضبط در بخش ابزار موسیقی حفظ شده‌اند. ورود و ادامه مهمان اکنون صفحه خانه را باز می‌کنند.

داده‌های پیشرفت، نشان‌ها و تنظیمات روی سرور ذخیره می‌شوند؛ `Modules/Social/profile-schema.sql` باید در سرور هدف نصب شود. تغییرات بک‌اند تنها محلی هستند و روی سرور اصلی منتشر نشده‌اند.

دانلود دوره با سقف یک گیگابایت در هر عملیات، بررسی اندازه فایل، رد تغییر مسیر HTTP و ذخیره خصوصی جداگانه هر حساب انجام می‌شود. درس‌های رمزدار باید پیش از دانلود باز شوند. بازکردن دانلودها به اینترنت برای بررسی مجدد مجوز نیاز دارد؛ پخش کاملاً آفلاین ارائه نشده است. تکمیل درس با اقدام صریح کاربر ثبت می‌شود.

تست‌ها: `flutter test --no-pub test/social_api_test.dart test/social_widget_test.dart test/profile_home_test.dart test/lesson_download_test.dart`.

ساخت: `flutter build apk --release --no-pub --target-platform android-arm64 --build-number 2`. روی این ماشین `PUB_HOSTED_URL=https://pub.flutter-io.cn` و `JAVA_TOOL_OPTIONS=-Djavax.net.ssl.trustStoreType=Windows-ROOT -Djavax.net.ssl.trustStore=NONE` برای مخزن بسته و گواهی‌های معتبر ویندوز لازم است. امضا همان کلید آزمایشی موجود پروژه است.
