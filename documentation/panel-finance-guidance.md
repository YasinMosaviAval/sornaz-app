# امور مالی، توضیحات و تب‌های سازمانی پنل

فیلتر سازمان، گزینهٔ آموزشگاه را حتی بدون ردیف مرتبط نمایش می‌دهد. امور مالی، فاکتورها و دوره‌های واقعی اشتراک را ترکیب می‌کند؛ جمع مبلغ، اقساط پرداخت‌شده و مانده از همان ردیف‌های فیلترشده محاسبه می‌شوند. ماه اول رایگان و قیمت پلن‌ها از API می‌آیند. خرید اشتراک پس از انتخاب پلن و تأیید کاربر به مسیر پرداخت موجود وب متصل است. خروجی Excel به صورت XLSX با سلول‌های متن و خروجی PDF با ستون‌های قابل مشاهده ساخته می‌شود.

اصلاح تکمیلی: تب‌بار سازمان اکنون در مسیر اختصاصی `BranchesPage` نیز حفظ می‌شود. تب تخفیف‌ها مجموعهٔ `discounts` را در جدول نمایش می‌دهد و سازمان تخفیف ثبت‌شده در فرم ویرایش قابل تغییر نیست. فیلتر گالری مالک‌های `owners` و شناسهٔ حساب `ownerId` را می‌خواند؛ شناسهٔ حساب شعبه با شناسهٔ خود شعبه اشتباه نمی‌شود. متن‌های اولیهٔ قالب وب به منبع مشترک PHP منتقل شده‌اند تا بدون ثبت دستی توضیح نیز در اپ قابل مشاهده باشند. پاسخ مالی جدید، اشتراک‌ها را مستقیماً در `subscriptions` می‌دهد و دکمه‌های خروجی حتی برای جدول خالی در دسترس‌اند. کش پنل نسخه‌بندی شده تا قرارداد قدیمی دوباره استفاده نشود.

آزمون‌های تکمیلی در `test/panel_remaining_parity_test.dart` ورود از منوی واقعی به سازمان، تعویض هر چهار تب، تب تخفیف‌ها، شناسهٔ مالک گالری، دریافت دو دورهٔ اشتراک بدون عملیات جانبی کاتالوگ و نمایش توضیح پیش‌فرض بدون override دیتابیس را می‌سنجند. فایل‌های `panel_api.dart` و `panel_form.dart` نیز در همین پوشه تغییر کرده‌اند. ساختار اصلی OMR، تنظیمات backend و worktree انتشار تغییر نکرده‌اند. مشاهده روی نسخهٔ نصب‌شده نیازمند انتشار API و نسخهٔ تازهٔ اپ است؛ در این کار خروجی برنامه ساخته یا منتشر نشده است.

نام و رنگ وضعیت ماه رایگان و عنوان وضعیت در انتظار پرداخت از دادهٔ اشتراک نمایش داده می‌شوند. فیلتر وضعیت اشتراک در `panel_filter_contract.dart` با عنوان‌های وب تطبیق داده شده است؛ از مقایسهٔ نادرست عنوان فارسی با کد وضعیت جلوگیری می‌شود.

تب‌های سازمان شامل برنامه زمانی، قوانین و تعطیلات؛ تب‌های کارمندها شامل برنامه اعضا و مرخصی‌ها؛ تب‌های ترم شامل مدیریت ترم و تخفیف است. فقط بخش‌های مجاز کاتالوگ در تب‌ها قرار می‌گیرند. فرم‌های جدید، فیلترها و ستون‌ها از قرارداد وب خوانده می‌شوند و fallback تولیدشده نیز به‌روز شده است.

توضیحات صفحات از داده‌های ترجمه‌شدهٔ وب خوانده می‌شوند؛ API مجوز ویرایش کاربر ۱ را در metadata هر بخش اعلام می‌کند و سرور مجدداً مجوز نوشتن را کنترل می‌کند. نمایش خطای مستقل توضیحات مانع استفاده از جدول نیست. کلاینت قدیمی با API قبلی به عملیات موجود دسترسی دارد؛ قابلیت تازه نیازمند فایل‌های وب ذکرشده در `docs/mobile-finance-guidance-deployment.fa.md` است.

برای انتقال انتخابی، زیرساخت پنل کامیت `c6e46f8` و تغییرات وب `1340a49` همراه API این کار لازم‌اند. وابستگی تازه‌ای به OMR یا تحلیل اجرای آزمایشی اضافه نشده است. فایل AGENTS.md به worktree انتشار منتقل نشود. خروجی برنامه، انتشار و migration جزو این کار نیستند.

فایل‌های برنامه: `lib/screens/Site/branches_page.dart`، `panel_navigation.dart`، `panel_organization_filter.dart`، `panel_presentation.dart`، `panel_resource_page.dart`، `panel_table_contract.dart`، `panel_web_contracts.dart`، `panel_finance.dart` و `panel_page_guidance.dart` در همان پوشه. آزمون جدید `test/panel_finance_expansion_test.dart` و fixture به‌روزشدهٔ `test/fixtures/panel_table_contracts.json` نیز بخشی از تغییر هستند.

اعتبارسنجی: ۵۸ آزمون مرتبط Flutter و ۳۸ مجموعه PHP فهرست انتشار وب موفق‌اند. دو آزمون سیاست تخفیف و تفکیک تعطیلات/مرخصی نیز با موتور Node موجود در VS Code اجرا و موفق شدند. تحلیل Dart خطا یا هشدار ندارد و موارد سبک نوشتن در سطح info گزارش شده‌اند. بررسی بودجهٔ اندازهٔ متدهای PHP همچنان خطاهای موجود پروژه را گزارش می‌کند. آزمون مرورگر به علت نبود Playwright و مرورگر تست اجرا نشده؛ پرداخت واقعی، MySQL و نمایش روی دستگاه تأیید نشده‌اند.
