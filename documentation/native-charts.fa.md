# کتابخانهٔ بومی نمودار اپلیکیشن

`fl_chart` نسخهٔ دقیق `1.2.0` به `pubspec.yaml` و `pubspec.lock` اضافه شد؛ وابستگی انتقالی جدید آن `equatable 2.1.0` است. نسخه و منبع سایر بسته‌های قفل‌شده تغییر نکرد. نصب از همان آینهٔ `pub.flutter-io.cn` موجود در lockfile پروژه انجام شد؛ تنظیم سراسری مخزن بسته‌ها تغییر نکرد.

این کتابخانه در Flutter بومی رسم می‌کند و برای نمایش نمودار به JavaScript، ECharts یا WebView وابسته نیست. مجوز آن MIT است. مرجع: [صفحهٔ رسمی بسته](https://pub.dev/packages/fl_chart).

## پوشش نسبت به وب

وب از Apache ECharts استفاده می‌کند. نمودارهای خطی/ناحیه‌ای، میله‌ای، دایره‌ای/دونات، پراکندگی، رادار و شمعی را می‌توان با این بسته پیاده کرد. این بسته جایگزین مستقیم تنظیمات JSON مربوط به ECharts نیست؛ داده و رفتار هر نمودار باید به API بومی تبدیل شوند.

انواع تخصصی مانند سنکی، درخت، treemap، sunburst، heatmap، boxplot، مختصات موازی و themeRiver معادل آمادهٔ یک‌به‌یک در این بسته ندارند. گیج، قیفی و میلهٔ تصویری هم به لایهٔ تکمیلی یا رسم اختصاصی نیاز دارند. افزودن این وابستگی به معنی تکمیل گالری ۱۹ نوع نمودار وب نیست.

## استفادهٔ فعلی

- `lib/components/charts/app_line_chart.dart`: آداپتور مشترک برای نمودار خطی، tooltip، برچسب‌ها و دادهٔ خالی/تک‌نقطه‌ای. رنگ، فونت و شعاع tooltip از تنظیمات مشترک ظاهر برنامه خوانده می‌شود.
- `lib/screens/Site/panel_tracking.dart`: نمودار روند بازدید روزانه اکنون از همین آداپتور و دادهٔ واقعی `page_views` استفاده می‌کند؛ painter اختصاصی قبلی حذف شد. سایر نمودارهای صفحه در این مرحله تغییر نکردند.
- `test/app_line_chart_test.dart`: بررسی دادهٔ صفر/نامعتبر، مقدار منفی و رعایت تنظیمات فونت/رنگ/شعاع.
- `test/panel_parity_completion_test.dart`: پوشش نمایش نمودار در صفحهٔ پایش و رگرسیون مسیرهای پنل.

تغییر وب/API لازم نبود. وابستگی جدیدی به OMR یا تحلیل عملکرد آزمایشی ایجاد نشد؛ فایل‌های این ویژگی با دو فایل وابستگی برای انتقال انتخابی آماده‌اند. worktree انتشار و تنظیمات شناسه/امضا/بک‌اند تغییر نکردند. بیلد، کامیت و پوش در این کار انجام نشد؛ نمایش واقعی و لمس tooltip روی دستگاه همچنان نیازمند آزمون است.

آزمون‌های `app_line_chart_test.dart` و `panel_parity_completion_test.dart` با مجموع ۱۴ سناریو موفق شدند. تحلیل ایستای آداپتور و آزمون اختصاصی و `git diff --check` نیز موفق بودند. فایل‌های تولیدشدهٔ ثبت پلاگین دسکتاپ که هنگام نصب بسته به‌صورت خودکار تغییر کرده بودند، به وضعیت اولیه برگشتند؛ این کتابخانه پلاگین بومی دسکتاپ جدیدی لازم ندارد.
